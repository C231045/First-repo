Project Title
Abdur Rahman - Personal Portfolio Website

✅ Project Description
A fully responsive, modern single-page personal portfolio website for Abdur Rahman, a Computer Science and Engineering student at International Islamic University Chittagong (IIUC). This website serves as a digital resume showcasing academic background, technical skills, projects, achievements, hobbies, publications, and professional contact information. The site features dark/light theme toggle, Google Sheets integration for contact form submissions, and comprehensive unit testing to ensure code reliability.

The portfolio is designed to help Abdur Rahman establish a professional online presence, showcase his work to potential employers, and provide an easy way for visitors to connect with him.

✅ Features
🎨 UI/UX Features
✅ Fully Responsive Design - Works perfectly on desktop, tablet, and mobile devices

✅ Dark/Light Theme Toggle - User preference saved in localStorage

✅ Smooth Scrolling - Seamless navigation between sections

✅ Modern Glassmorphism Effects - Elegant visual design with hover animations

✅ Interactive Elements - Hover and click animations on cards, buttons, and images

✅ Profile Image with Glow Effect - Eye-catching profile picture with animated border

📄 Content Sections
✅ Hero Section - Introduction with social media links and CTA buttons

✅ About Me - Personal introduction and career overview

✅ Skills Display - Technical skills with icons (C, C++, Java, Python, HTML, CSS, JavaScript, Git)

✅ Education Timeline - Academic history with visual timeline

✅ Areas of Interest - Web Development, Problem Solving, Software Engineering, UI/UX Design

✅ Statistics Counter - Skills count, courses completed, current semester, career goal

✅ Academic Projects - 4 project cards with descriptions

✅ Achievements - Year-wise achievement display with certificate download links

✅ Hobbies - 6 hobby cards with icons and descriptions

✅ Publications - Upcoming research and technical articles

✅ Contact Form - Fully functional with Google Sheets integration

🔧 Technical Features
✅ Google Sheets Integration - Contact form data saves to Google Sheets and sends email

✅ PDF CV Download - One-click download of CV

✅ Social Media Integration - GitHub, Facebook, LinkedIn links

✅ Certificate View - Click to view achievement certificates

✅ Form Validation - Required fields validation

✅ Success/Error Messages - User feedback for form submission

🧪 Unit Testing
✅ Email Validation Tests - 3 test cases (valid, invalid, empty)
